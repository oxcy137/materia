COLOCAR TEXTURAS REALES AQUÍ
=============================
Sistema de archivos esperado (cualquiera de estos se detecta automáticamente):

  albedo.webp | albedo.jpg | albedo.png     → color base (obligatorio)
  diffuse.webp | diffuse.jpg                → alias de albedo
  basecolor.webp | basecolor.jpg            → alias de albedo
  normal.webp | normal.jpg                  → normal map (opcional)
  roughness.webp | roughness.jpg            → roughness (opcional)
  height.webp | height.jpg                  → displacement (opcional)
  ao.webp | ao.jpg                          → ambient occlusion (opcional)

Mientras no existan, la web genera texturas procedurales de mármol
automáticamente con vetas únicas por piedra.
